工具	                                                          負責工作
STM32CubeIDE for VS Code	STM32 專案編譯、下載與除錯
STM32CubeMX	                       設定腳位、時脈及周邊，產生初始化程式
GitHub Copilot	                       在 VS Code 內提供 AI 補全、對話與程式修改
ST-LINK	                                       連接開發板，進行實機燒錄與除錯
