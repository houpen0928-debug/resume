填寫後按「前往 GitHub 發布」，登入具有此儲存庫寫入權限的帳號，再按 Commit changes 儲存。網站會自動更新，通常需幾分鐘。此表單不會直接發布，也不會要求密碼。

Fill in the form, continue to GitHub, then use Commit changes with an authorized account. Publishing usually takes a few minutes. This form never asks for a password.

管理／編輯已發布文章 / Manage published posts

編輯既有文章：開啟上方管理連結，選擇文章並按鉛筆圖示，修改後儲存。文章可用中文或英文撰寫，Blog 兩版入口都會列出；內容不會自動翻譯。離開本頁前可下載備份。
