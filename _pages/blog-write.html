填寫後按「前往 GitHub 發布」，登入具有此儲存庫寫入權限的帳號，再按 Commit changes 儲存。網站會自動更新，通常需幾分鐘。此表單不會直接發布，也不會要求密碼。

Fill in the form, continue to GitHub, then use Commit changes with an authorized account. Publishing usually takes a few minutes. This form never asks for a password.

附件會公開顯示於日誌。每個檔案最多 20 MB，合計最多 50 MB。 / Attachments are public. Maximum 20 MB per file, 50 MB total.

    有附件時會下載發布套件：解壓縮 ZIP，開啟下方「上傳發布套件」，將解壓縮後的 _journal 與 files 兩個資料夾一起拖入 GitHub，再按 Commit changes。請勿直接上傳 ZIP。文章與附件會一起發布。

    With attachments, download and unzip the publishing package. Drag both _journal and files folders into GitHub using the link below, then commit. Do not upload the ZIP itself.

    上傳發布套件 / Upload publishing package

    管理／編輯已發布文章 / Manage published posts

    編輯既有文章：開啟上方管理連結，選擇文章並按鉛筆圖示，修改後儲存。文章可用中文或英文撰寫，Blog 兩版入口都會列出；內容不會自動翻譯。離開本頁前可下載備份。
